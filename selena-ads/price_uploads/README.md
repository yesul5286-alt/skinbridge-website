# Upload area — not an approved price ledger
Add PDFs, screenshots or a text/CSV file here to create a **manual price review report** in GitHub Actions.

The workflow will NOT blindly replace data/prices.csv based on raw OCR. Once a person verifies the item name, unit/cc/shots/kJ, amount, VAT status, period, and source, edit data/prices.csv and commit. This triggers new 15-card draft rendering.

No private patient data or medical records should be uploaded here.
